☯ 这是什么

一个多用户版「复盘教练」（典出《论语》"吾日三省吾身"）。注册后用引导式提问把一天的事、担忧和觉察聊出来， 最后沉淀成带 Reflection 和 Tags 的结构化 markdown，存进你自己的账户， 随时按天导出为 md（Obsidian 可直接打开）。

怎么用：
1. 登录（需要邀请码注册，找管理员索取）。
2. 选模式：🌅 晨间规划 / 🌙 晚间复盘 / 💭 自由对话。
3. 教练逐个引导提问，想换角度点下方快捷指令。
4. 聊完点右上角「生成复盘并保存」→ 存入账户。
5. 「📚 我的存档」里按天浏览、删除，或导出当日 md / 区间 zip。

关于 AI：对话由 Supabase Edge Function 代理，AI key 只存在 Supabase 的环境变量里， 前端和代码仓库里都没有。
