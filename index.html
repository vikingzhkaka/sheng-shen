☯ 这是什么

一个私人复盘教练（典出《论语》"吾日三省吾身"）。注册后用引导式提问把一天的事、担忧和觉察聊出来， 最后沉淀成带 Reflection 和 Tags 的结构化 markdown，存进你自己的账户， 随时按天导出为 md。

怎么用：
1. 登录（需要邀请码注册，找管理员索取）。
2. 选模式：🌅 晨间规划 / 🌙 晚间复盘 / 💭 自由对话（默认进入晨间）。
3. 教练逐个引导提问；想换角度，点下方的快捷指令：💡 建议 / 🧠 思考 / 🔭 不同观点 / 🔬 分析 / 👣 下一步。
4. 输入框左下角是模型切换：V4 快速文字 / 6.7 看图。想让教练"看"图，点 📎 附图（自动切到 6.7）。
5. 聊完在输入区点「🌿 生成复盘」→ 自动存入账户。
6. 「📚 存档」里按天浏览、删除，或导出当日 md / 区间 zip。
